# סקירת אתר המקור: ethical-supplements.com

> סעיף 0.1 בבריף. נסקר ב-2026-11-02. הנתונים הגולמיים נמצאים ב-`migration/out/`
> (`raw/pages.json`, `inventory.csv`, `screenshots/`). ההרצה מחדש:
> `node migration/01_fetch_content.mjs && node migration/02_inventory.mjs`.

## פלטפורמה

- וורדפרס עם Elementor Pro, שרת nginx ו-PHP 8.1. כל העמודים הם `page` (אין פוסטים
  אמיתיים, יש רק "Hello world").
- תוספים רלוונטיים: Rank Math (SEO), Complianz (באנר עוגיות), Jet Menu, Essential Addons,
  Akismet, Code Snippets.
- WP REST פתוח (`/wp-json/wp/v2/pages`). יש בו 57 עמודים ו-362 קבצי מדיה (webp, jpeg,
  png, ‏22 קבצי PDF ו-8 מודלי ‎3D (`.glb`)).
- `sitemap.xml` מפנה לדף הבית, וה-robots מצביע על sitemap של rankmath.com (שגוי). רשימת
  הכתובות נלקחה לכן מה-REST.
- אין חנות מקוונת ואין מחירים. האתר הוא קטלוג שמפנה לנקודות מכירה.

## ממצאים ובעיות באתר הקיים

- בתפריט הראשי יש קישורים שגויים: לקטופר מפנה לאליוויום, רלקטון ל-קוגני Bright, וכמה פריטי
  ליפוזמין ל-Mg. האתר החדש ייבנה מה-CMS, כך שהבעיה תיפתר מעצמה.

- רוב הכתובות יושבות תחת `/עמוד-הבית/...`. במעבר נקצר אותן.
- הפונטים נטענים מ-`dev.www.ethical-supplements.com` (http), וזה גורם לתוכן מעורב.

## שאלות פתוחות ללקוח

1. **דומיין:** האתר החדש יחליף את `www.ethical-supplements.com` (באותו דומיין) או יעלה על
   `category-5.xyz` (‏301 מהישן)? מ-הסשן הזה `category-5.xyz` עדיין לא נגיש.
2. **חנויות:** לייבא את 600+ הנקודות מ-Storepoint למפה שלנו (צריך ייצוא CSV מ-Storepoint,
   כי ה-API שלהם חסום מכאן) או להשאיר את ההטמעה?
3. **שאלות ותשובות:** לבנות עמוד FAQ (מאיזה תוכן?), להשאיר את הצ'אטבוט של Zapier, או
   שניהם?
4. **פונט Alpha:** יש רישיון לשימוש בווב? אם אין, להציע חלופה.
5. **מודלי ‎3D, וידאו ו-PDF במוצרים:** להעביר את כולם?
6. **אינסטגרם / רשתות:** לא נמצאו קישורים לרשתות באתר. יש חשבונות?
7. **רשימת תפוצה** בפוטר: לאיזה שירות היא מחוברת?
