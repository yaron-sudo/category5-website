# חיבור טופס צור קשר דרך Web3Forms

הטפסים באתר (צור קשר, הטופס בעמוד הבית, ההרשמה לניוזלטר בפוטר) נשלחים דרך Web3Forms
ברגע שמוגדר משתנה הסביבה `PUBLIC_WEB3FORMS_KEY`, בדיוק כמו באתר נייטשרסייג. ללא המפתח
הטפסים נשלחים ל-`/api/contact` (שרת המייל של האתר, שדורש הגדרת MS_* / SMTP_* / RESEND).

## שלב 1: מפתח גישה (5 דקות)

1. נכנסים ל-<https://web3forms.com>.
2. בשדה **Email** מקלידים את תיבת הדואר שאליה יגיעו הפניות (`info@ethical-supplements.com`)
   ולוחצים **Create Access Key**.
3. Web3Forms שולח מייל לאותה תיבה. פותחים אותו ולוחצים **Verify** / **Activate**.
4. במייל מופיע ה-Access Key (מחרוזת בפורמט `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`). מעתיקים אותו.

המפתח מזהה רק את תיבת היעד, ולכן הוא ציבורי מעצם טבעו (נמצא בקוד שרץ בדפדפן).
אי אפשר להשתמש בו כדי לקרוא פניות, רק כדי לשלוח אליכם מייל.

## שלב 2: הגדרה ב-Vercel

1. ב-Vercel: הפרויקט של האתר → **Settings** → **Environment Variables**.
2. **Add New**:
   - Key: `PUBLIC_WEB3FORMS_KEY`
   - Value: המפתח משלב 1
   - Environments: לסמן **Production** וגם **Preview**.
3. **Save**.
4. המפתח נאפה לתוך האתר בזמן הבנייה, לכן חייבים פריסה מחדש:
   **Deployments** → שלוש הנקודות ליד הפריסה האחרונה → **Redeploy**
   (או לדחוף commit כלשהו).

## שלב 3: בדיקה

1. באתר החי: `/contact` → ממלאים את הטופס → **שליחה**. אמור להופיע "נשלח" מתחת לכפתור.
2. בודקים שהמייל הגיע לתיבה (נושא: "פנייה מהאתר — <שם>"). אם לא, לבדוק בספאם ולסמן "לא ספאם".
3. בודקים גם את הניוזלטר בפוטר (נושא: "הרשמה לרשימת התפוצה — <אימייל>").

## מה מגיע במייל

- פניות: שם, טלפון, אימייל, הודעה (כולל "נושא הפנייה" ו"מוצר" מעמוד צור קשר), והעמוד שממנו נשלח.
- ניוזלטר: האימייל בלבד.
- **Reply** על המייל עונה ישירות לפונה (השדה Reply-To מוגדר לאימייל שלו).

## מגבלות ואפשרויות

- החבילה החינמית: 250 פניות בחודש. מעבר לזה נדרשת חבילה בתשלום או מעבר ל-`/api/contact`.
- בלוח הבקרה של Web3Forms (אחרי הרשמה, אופציונלי) אפשר להוסיף נמענים נוספים,
  מייל אישור אוטומטי לפונה, Slack ו-Webhooks.
- הגנה מבוטים: Web3Forms מסנן ספאם בצד שלו, והאתר מתעלם מטפסים שנשלחו פחות משנייה
  אחרי טעינת העמוד. אם יגיע ספאם, אפשר להפעיל בלוח הבקרה שלהם hCaptcha.
- כדי לחזור לשרת המייל של האתר: מוחקים את המשתנה מ-Vercel ופורסים מחדש.

## מה בקוד

- `astro/src/layouts/Site.astro`: הסקריפט של הטפסים. אם `PUBLIC_WEB3FORMS_KEY` מוגדר הוא
  שולח JSON ל-`https://api.web3forms.com/submit`; אחרת ל-`/api/contact`.
- `vercel.json` (שורש הריפו): ה-CSP כבר מתיר `api.web3forms.com` (connect-src ו-form-action).
- `astro/.env.example`: תיעוד המשתנה.
